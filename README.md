# Jamu

An app to help learn Japanese.

     height="80">](https://f-droid.org/packages/jp.nonbili.jamu/)

Or download the latest APK from the [Releases Section](https://github.com/nonbili/Jamu/releases/latest).

## Features

- Gojuon (五十音)
- Numbers (数字)
- NHK Easy News
